# 🖼️ Meme Generator

## 📖 Description

This project is a simple and interactive Meme Generator developed using HTML5, CSS3, and JavaScript.

Users can select an image, add top and bottom text, customize the text size and color, and download the completed meme as a PNG image.

## ✨ Features

- 🖼️ Upload an image from the device
- ✏️ Add top text
- ✏️ Add bottom text
- 🔤 Change text size
- 🎨 Change text color
- 🖌️ Canvas-based meme creation
- 📥 Download the generated meme
- ⚡ Live preview while editing
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Canvas API
- FileReader API
- DOM Manipulation
- Event Listeners
